# Data Source & Simulation Design

This document explains the synthetic KOL dataset used by the TikTok Shop KOL Matrix Optimizer.

---

## 1. Schema (12 Fields)

The dataset is generated by `data/generator.py` and serialised to `data/sample_kols.json` and `data/influencers_mock.csv`. Each record contains the following fields, generated in this exact order:

| Field | Type | Range / Values | Description |
|-------|------|----------------|-------------|
| `id` | int | 1, 2, 3, … | Sequential unique identifier |
| `name` | str | `"KOL_{id}"` | Display name |
| `country` | str | `MY` / `ID` / `TH` / `PH` | Target Southeast Asian market |
| `category` | str | `beauty` / `tech` / `fashion` | Content category |
| `followers` | int | 1,000 – 5,000,000 | Total follower count |
| `engagement_rate` | float | 0.001 – 0.30 | Average engagement as a proportion (likes + comments + shares) / views |
| `fit_score` | float | 0.30 – 1.00 | Cultural / brand fit score for the target market |
| `cost` | float | 50 – 100,000 | Hiring fee (USD) per sponsored post |
| `avg_views` | int | ≈ followers × 0.3 ± 5% | Average video views over the last 30 days |
| `avg_likes` | int | avg_views × engagement_rate | Average likes per video |
| `gender_ratio` | float | 0.00 – 1.00 | Female audience proportion (1 = 100% female) |
| `age_group` | str | `"18-24"` / `"25-34"` / `"35+"` | Dominant audience age bracket |

The `tier` field shown elsewhere in the system (`Mega` / `Macro` / `Micro` / `Nano`) is **derived from `followers`** at runtime by `engine.scoring.explainer.get_tier()`, not stored in the data file.

---

## 2. Why Synthetic Data?

The dataset is fully simulated rather than scraped from live platforms, for two reasons:

- **No public TikTok creator API.** TikTok does not provide an open developer endpoint for browsing creator pricing, demographics, or historical performance. Web scraping is rate-limited and prohibited under their Terms of Service.
- **Commercial sensitivity.** Real influencer hiring fees, audience demographics, and historical conversion data are covered by non-disclosure agreements between brands, agencies, and creators. Using synthetic data avoids any privacy or contractual risk while still allowing realistic algorithm evaluation.

The synthetic parameters are calibrated against publicly available industry reports on Southeast Asian influencer marketing to keep the distributions statistically plausible.

## 3. Distribution Assumptions

### 3.1 Tier Distribution

The population follows a real-world long-tail distribution:

| Tier | Follower Range | Share | Reasoning |
|------|----------------|-------|-----------|
| **Nano** | 1,000 – 9,999 | 40% | High-volume, niche communities |
| **Micro** | 10,000 – 99,999 | 35% | High engagement, precise targeting |
| **Macro** | 100,000 – 999,999 | 20% | Broad reach with credibility |
| **Mega** | 1,000,000 – 5,000,000 | 5% | Celebrity tier, scarce supply |

Implementation in `generator.py`:
```python
tier_roll = random.uniform(0, 100)
if tier_roll < 40.0:  # Nano
elif tier_roll < 75.0:  # Micro
elif tier_roll < 95.0:  # Macro
else:  # Mega
```

### 3.2 Inverse Engagement Rule

Engagement rate is **inversely proportional** to follower count, reflecting the well-documented industry observation that smaller creators have more loyal audiences:

```python
base_engagement = max(0.01, 100000 / followers)
engagement_rate = min(0.3, max(0.001, base_engagement * random.uniform(0.5, 1.5)))
```

This produces engagement rates roughly in the ranges:
- Nano: 10% – 30%
- Micro: 5% – 15%
- Macro: 1% – 5%
- Mega: 0.1% – 1%

### 3.3 Cost Correlation

Hiring fee scales with both reach (`followers`) and engagement quality:

```python
base_cost = followers * engagement_rate * 0.05
cost = max(50.0, min(100000.0, base_cost * random.uniform(0.8, 1.2)))
```

The ±20% multiplicative noise simulates market variance between creators of similar size.

### 3.4 Country, Category, Demographics

These four fields are sampled uniformly at random:
- `country` ∈ {MY, ID, TH, PH}
- `category` ∈ {beauty, tech, fashion}
- `gender_ratio` ∈ U(0, 1)
- `age_group` ∈ {18-24, 25-34, 35+}

`fit_score` is sampled uniformly from [0.3, 1.0] — bounded above zero to model that any KOL pursued by a brand has at least minimal market alignment.

## 4. Reproducibility

The generator accepts a `seed` parameter (default `42`) and a `--num` CLI flag:

```bash
# Default 300 KOLs
python data/generator.py

# Custom pool size for scalability experiments
python data/generator.py --num 500
```

The same `seed` always yields the same dataset, which is essential for fair algorithm comparison and for the reproducibility requirements of the project report.

## 5. Data Files

| File | Format | Used By |
|------|--------|---------|
| `data/sample_kols.json` | JSON array | Backend `/optimize`, `/kols`, `/kol/{id}` endpoints |
| `data/influencers_mock.csv` | CSV with header | Manual inspection, future BI tooling |

Both files contain identical data and are regenerated together by every `generator.py` run.
### Behavioral Rules
* **Inverse Engagement Logic:** Engagement rates are modeled to be **inversely proportional** to follower counts. As a creator's follower base expands into Macro and Mega tiers, their percentage-based engagement decays naturally.
* **Positive Cost Correlation:** Total booking `cost` is modeled with a **strong positive correlation** to estimated user `reach`. Larger reach metrics scale the baseline asset valuations upward.
